Files:
- index.html: complete single-file bilingual website. CSS, JavaScript and the original supplied logo are embedded.

Preview:
Open index.html in any modern browser. An internet connection is needed for Google Fonts and the remote architectural photography.

Publish with GitHub Pages:
1. Create/open a GitHub repository.
2. Upload index.html (README.txt is optional) to the repository root.
3. Open Settings > Pages.
4. Select Deploy from a branch, choose main and /(root), then Save.
